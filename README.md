# My Traveller Universe

This is the source code of My Traveller Universe, a tool for building and managing a Traveller RPG universe: sectors,
subsectors, star systems and everything in them. It is built for Deepnight campaigns and for referees charting their
own space.

## Using My Traveller Universe

The easiest way to use it is the hosted site at **[mytravelleruniverse.net](https://mytravelleruniverse.net)**, which
runs this code. There is nothing to install.

With it you can:

* organise a campaign as sectors, subsectors and parsecs
* generate whole subsectors of star systems from a YAML build configuration, with live progress
* record stars, planets, moons, belts, gas giants and other objects in detail
* explore an interactive starmap, subsector maps and system orbit maps
* keep notes in Markdown, and export systems as Markdown for session prep
* search your rulebooks

## Development

Requires Ruby, PostgreSQL, Node and the external generator service (`config.x.generator_service`).

```bash
bin/dev                  # start the development server
bin/rails test           # run the tests
bundle exec rubocop      # lint
```

See [CLAUDE.md](CLAUDE.md) for architecture notes.
