### Manoeuvre Drive Parameter

The vessel record now accepts a Manoeuvre Drive rating (0–10). This parameter is
stored in the ship registry, validated against the permissible drive classification
range, and presented on both the vessel summary display and the configuration form.

### Referee Hex Navigation Protocol

Referee operators may now initiate a direct link to a star system record by
holding the Control key whilst selecting a hex on the cartographic display. The
associated system record opens in a secondary viewport, leaving the primary chart
state unmodified. The function is restricted to referee-classified sessions.
