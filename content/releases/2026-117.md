### Jump Survey Protocol

Star system records now carry a Jump Survey panel. Operators may initiate a
localised cartographic scan at radii J-1 through J-6, producing a hex map
centred on the designated system and clipped to the precise hexagonal boundary
of the selected jump envelope. The resulting chart is presented in an overlay 
panel. A signed SVG embed link is provided for integration into external displays
or briefing materials.

The survey panel appears on both star system records and on stellar object
records that belong to a charted system. Jump maps are cached against the
current state of all parsecs, systems, and regions within the viewport;
subsequent requests within the same configuration state incur no regeneration
cost.

### Cartographic Display Controls

The navigation status bar now carries dedicated magnification controls for both
Hex Map and Full Journey display modes. Operators may increase or decrease the
rendered scale of the cartographic display by activating the magnifying glass
controls. All scale adjustments are clamped within the established minimum and
maximum hex size parameters.

### Map Refresh Restored to Operational Status

The Refresh Map control has been restored to full operational capability. A
prior condition caused the control to produce no observable effect when the
displayed viewport had already been fully loaded into the local system register,
as the navigation subsystem only dispatched acquisition requests for parsec
positions absent from the register. The control now purges all parsec entries
within the current viewport prior to re-issuing acquisition requests, ensuring
that all positions are reloaded from the navigation database on demand.
