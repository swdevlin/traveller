### Stellar Object Analysis — Enhanced Data Display

The stellar object analysis console has received an upgrade to the scope and organisation of information presented to 
the operator. Additional physical, atmospheric, and cultural data is now available for surveyed worlds, presented in a
structured format suited to rapid consultation in the field.

### Travel Time Table

A new Travel Time Table is accessible from the system sidebar. Activating the control presents a matrix overlay displaying
calculated transit times between all bodies in the current solar system. The operator selects a manoeuvre drive rating 
from the selector at the head of the table; all times update accordingly.
