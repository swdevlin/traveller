### Jump Route Computation

The navigation subsystem now incorporates an automated route-plotting facility accessible from any star system or stellar 
object record. Activating the Route function opens the navigation modal, wherein the operator specifies an origin system,
a destination system, a maximum jump rating (J-1 through J-6), and a refuelling constraint — unrestricted, commercial
starport only (Class D or better), or wilderness refuelling only (gas giant presence required).
