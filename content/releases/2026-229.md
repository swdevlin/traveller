### T5 Tab Delimited Ingestion

The build default apparatus accepts a third data source: a T5 Tab Delimited file,
fed directly into the console by the operator rather than drawn down from an
external relay. Presented with a whole-sector file, the apparatus distributes
the resulting build specifications across the sixteen subsector stations
automatically; presented with a file at the subsector station itself, only the
rows falling within that station's own hexes are consulted. The uploaded file
supersedes any build plan already entered, with the survey index setting alone
still honoured from the Settled Space control on the sector register. At the
point of sector creation, an uploaded file is folded directly into the initial
generation run for each subsector.

### Rulebook Catalogue Filtering

The Library register gains a category selector alongside its existing search
field.
