### Tidal Lock

Gravitational coupling relationships are now recorded and displayed across
survey records. Where a body is tidally locked to another — moon to parent
planet, planet to primary stellar body, or any analogous orbital resonance —
the locked body's orbital data section carries a reference to the constraining
object. Should the target body be subsequently purged from the survey database,
the coupling reference is automatically voided and cleared from the record.

### Sophont Cartographic Classification Codes

Campaign configuration now accepts colour classification codes for systems
registered as harbouring extant native sophont species, and for those bearing
historical records of extinct sophont civilisations. The assigned codes are
applied to the hex matrix background of all affected systems across cartographic
output channels — subsector maps, viewport renders, and the interactive
navigation display.

Allegiance classification takes precedence in all cases; sophont colouring is
applied only to systems not otherwise distinguished by allegiance data. Default
classification codes are pre-loaded upon campaign initialisation.

### Sophont Colour Display Parameter

The display parameter governing sophont hex classification on server-rendered
SVG cartographic output is now independent of the colour assignment register.
Discrete enable/disable parameters for native and extinct sophont classification
govern rendering across subsector exports and the all-sectors cartographic
output. Deactivating a parameter suppresses classification rendering on those
output channels without modifying the stored colour value.

The interactive navigation display operates under a separate directive.
Sophont classification is rendered unconditionally in referee mode and withheld
in player mode; the SVG display parameters have no effect on this channel.

### Captive Government Suppression Protocol

A control parameter is now available in campaign configuration governing whether
the generation system may assign Government Classification Code 6 — Captive
Government — during subsector population procedures. A captive government
designation indicates that a system operates under direct political authority
of an external power, a disposition more correctly determined by referee
directive than derived through automated generation, particularly in
deep-space exploration operational contexts.

The parameter defaults to suppressed for Deepnight Revelation campaigns and
active for Charted Space and Homebrew campaigns. Individual subsector build
specifications may declare `allowCaptiveGovernment` to override the
campaign-level parameter for a given generation run; the per-subsector
declaration takes precedence in all cases.
