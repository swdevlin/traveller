### Realistic Star Distribution Parameter

Campaign configuration now accepts a Realistic Star Distribution directive. When
active, the generation system applies empirically-weighted stellar class
probabilities during star placement, biasing output toward the true frequency
distribution of stellar types rather than the balanced spread assumed by the
default Traveller generation procedure. The directive is forwarded to the
generation service for all generation channels — individual star system
creation, build configuration runs, and bulk subsector population operations.

The parameter defaults to inactive upon campaign initialisation, preserving
the standard Traveller stellar frequency distribution. The governing optional
rule is specified in *World Builder's Handbook*, page 16.
