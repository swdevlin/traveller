### Moon Main World Designation

When the designated main world of a star system is a satellite body, the star
system survey table now marks the parent body with the main world indicator. This
allows the Referee to identify the relevant orbital body without navigating to the
satellite registry. The procedural synthesis importer has been extended to support
moon main world assignments, and the build configuration schema now accepts
satellite main world specifications.
