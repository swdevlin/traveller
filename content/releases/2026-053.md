### Main World Designation Console

The star system survey display now identifies the designated main world and presents
its Universal World Profile alongside the other primary survey parameters. An inline
edit control permits the operator to reassign the main world designation to any
catalogued body in the system that carries a valid UWP.

### Base Registry Editor

Assigned base codes for a star system are now displayed in the primary survey
header alongside the main world UWP. An edit interface allows the operator to add
or remove base designations from the full facility registry.

### Stellar Classification Parameter Autofill

The stellar data core editor now queries the onboard synthesis engine whenever the
operator modifies a star's spectral type, subtype, or luminosity class. Derived
physical parameters — mass, diameter, effective temperature, luminosity, estimated
age, minimum allowable orbit, habitable zone central orbit, and chromatic
classification — are automatically populated from the engine response. All autofilled
values remain fully editable and may be overridden at operator discretion.
