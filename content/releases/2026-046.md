### Stellar Data Core Editor

Individual star records may now be modified via a dedicated data core edit interface.
The edit interface is accessible from both the star survey display and the stars
registry table within the parent system view.

### Terrestrial Planet Data Core Enhancements

The terrestrial planet data core editor has been extended with environmental and
physical survey fields. Atmospheric classification codes (0–H, extended hex) and
atmospheric composition may now be recorded via the edit interface. Hydrographic
coverage codes (0–A), predominant surface liquid type, and liquid distribution
patterns are likewise editable. A planetary size code field has been added to the
physical data section.

### Rogue Registration Console

The rogue stellar object registration form has been refitted to conform with
standard console interface conventions. Field presentation, error reporting, and
layout now match the patterns established across all other data core edit interfaces.
A redirect fault that could deposit the operator at an unrelated survey record after
successful registration has been corrected.

### Orbital Sequence Recalibration

Deletion of a stellar body, secondary star, or companion star now triggers automatic recalibration
of orbital sequence designators for all remaining bodies in the parent system.

### Star Orbiting Bodies Registry

The orbiting bodies table on the star survey display now includes operational controls
for editing and deleting individual bodies, matching the interface established on the
parent star system view. A UWP column has been added, displaying the Universal World
Profile for terrestrial planets and the size code for gas giants.

### Transit Diagram Viewport Correction

The star system transit diagram now maintains its native dimensions and provides
a horizontal scroll region when the diagram exceeds the available console width.
A prior rendering fault caused the diagram to compress into the viewport, distorting
orbital spacing at higher zoom levels.

### Rogue Registry Display Correction

The rogue stellar object table no longer renders a navigational reference in the
name column for objects that have not been assigned a designation. Unnamed objects
now display a blank name field as expected.
