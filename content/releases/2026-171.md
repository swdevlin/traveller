### Rogue Object Integration in Subsector Generation

The subsector generation matrix now supports the inclusion of rogue stellar objects
— bodies that traverse the interstellar medium unbound to any stellar primary.

### Sector Display Mode Selection

The sector index console now provides a display mode selector, permitting
operators to toggle between a visual grid representation and a tabular data listing.
The selected mode is retained between navigation events, allowing persistent configuration
of the preferred data presentation format.
