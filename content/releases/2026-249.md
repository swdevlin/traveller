### Populated World Eccentricity Ceiling

A new campaign directive, Limit Populated World Eccentricity, constrains
every generated world of population code 3 or greater to the three lowest
rolls of the Eccentricity table — an orbit of 0.09 or less — unless the
world already carries an eccentricity of its own specification, which takes
precedence. The directive is disabled by default. A single build
configuration may override the campaign directive for that generation run
via its own limitedMainWorldEccentricity flag.

### Explicit Eccentricity Specification

Build configurations may now stipulate an exact eccentricity for a main
world, or any counted or stellar body, in place of leaving the figure to
procedural roll. Where a value is declared, the generator defers to it
above all default reckonings.
